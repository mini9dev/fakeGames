# 🕹️ FakeGames – Launcher (v2.0)

FakeGames is a lightweight experimental game collection, fully managed through the **FakeGames Launcher**.

## 🚀 Download

## 🎮 How it works

1. Install the setup  
2. Choose language (FR / EN)  
3. Browse available FakeGames  
4. Install & fake play instantly

- 🌍 FR / EN support
